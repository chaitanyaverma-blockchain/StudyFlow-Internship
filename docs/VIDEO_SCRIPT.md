# 🎬 StudyFlow – Demo Video Script

**Target Duration:** 2–4 minutes

---

## 1. Introduction (15 seconds)

> "Hi, I'm Chaitanya Verma. This is StudyFlow — a student task management application I built as part of my Full Stack Development Internship. It covers Tasks 1 through 5, demonstrating server rendering, validation, responsive design, dynamic DOM manipulation, and a REST API."

---

## 2. Homepage (15 seconds)

- Show the homepage at `http://localhost:3000`
- Highlight the hero section, feature cards, and "How It Works" steps
- Scroll down to the call-to-action section
- Point out the clean, professional design

---

## 3. Add Task & Validation (30 seconds)

- Click "Add Your First Task" to navigate to `/tasks/new`
- **Show validation:** Try submitting an empty form — point out the error messages
- **Show live feedback:** Type in the description field and note the character counter
- **Show deadline status:** Select a date and observe the "Due in X days" message
- **Fill in a valid task:** Complete all fields with valid data
- Submit the task — observe redirect to the task dashboard

---

## 4. Task Dashboard (30 seconds)

- Show the task dashboard at `/tasks`
- Point out the summary statistics cards (Total, High Priority, Pending, Completed)
- Show the task card with all its details
- Click "View Details" — show the details modal with complete task information
- Close the modal

---

## 5. Search, Filter & Sort (30 seconds)

- **Add 2–3 more tasks** with different priorities and subjects (can be quick)
- **Search:** Type a keyword in the search bar — show tasks filtering in real-time
- **Filter:** Click "High Priority" filter button — show only high priority tasks
- **Filter:** Click "Pending" — show only pending tasks
- **Sort:** Change sort to "Priority: High to Low"
- **Reset:** Click "Reset Filters" to show all tasks again

---

## 6. Edit, Delete & Status Toggle (30 seconds)

- **Edit:** Click "Edit" on a task — modify the title or priority — save changes — observe the toast notification
- **Status toggle:** Click "Mark Complete" on a task — observe the card becomes semi-transparent and badge changes to "Completed"
- **Delete:** Click "Delete" on a task — observe the confirmation modal — click "Cancel" to demonstrate cancel functionality — then click "Delete" again and confirm — observe the task removed and toast notification

---

## 7. Dark Mode & Responsive Design (20 seconds)

- **Dark mode:** Click the 🌙 theme toggle in the navbar — show the dark mode
- Navigate to a different page — show theme persists
- Refresh the page — show theme still persists
- **Responsive:** Open browser DevTools and resize to mobile width (~375px)
- Show the hamburger menu working
- Show cards stacking vertically

---

## 8. REST API (15 seconds)

- Open a new browser tab
- Navigate to `http://localhost:3000/api/tasks`
- Show the JSON response with all tasks
- Navigate to `http://localhost:3000/api/tasks/1`
- Show the single task JSON response
- Mention that POST, PUT, DELETE, and PATCH also work via API

---

## 9. API Documentation (10 seconds)

- Navigate to `http://localhost:3000/api-docs`
- Briefly scroll through the documentation page
- Point out the temporary storage notice
- Show the endpoint cards with request/response examples

---

## 10. GitHub Repository (10 seconds)

- Show the GitHub repository at `https://github.com/chaitanyaverma-blockchain/StudyFlow-Internship`
- Point out the branch structure (task branches + main)
- Show the tags (task-1-complete through task-5-complete, v1.0.0)
- Mention the README and docs folder

---

## 11. Conclusion (15 seconds)

> "That's StudyFlow — a complete student task management application built across 5 internship tasks. It demonstrates HTML forms, client and server validation, responsive design with Bootstrap 5, dynamic DOM manipulation, and a full REST API with CRUD operations. Thank you for watching!"

---

## Tips for Recording

- Use a clean browser with no bookmarks bar visible
- Pre-create 2–3 sample tasks before recording to save time
- Keep the browser at a comfortable width (around 1280px)
- Speak clearly and at a moderate pace
- Use keyboard shortcuts where possible to keep the flow smooth
- Total target: Under 4 minutes
